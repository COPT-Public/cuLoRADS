# Contributing

This repository distributes the compiled cuLoRADS application and its public
documentation. It is not the implementation-source contribution channel.

Use <https://github.com/COPT-Public/cuLoRADS/issues> for reproducible binary,
documentation, and packaging reports. Include the release version and archive
checksum, exact command, minimal shareable input, operating system, GPU and
driver details, exit status, and complete output. Do not attach confidential
models or data.

Changes to documentation or packaging must preserve the binary checksum unless
a replacement archive is deliberately released. A replacement archive requires
a new checksum, dependency/license review, and GPU validation.

Follow the COIN-OR code of conduct:
<https://www.coin-or.org/code-of-conduct/>.
